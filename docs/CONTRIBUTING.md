# Guia de Contribuição 🤝

Agradecemos o seu interesse em contribuir com o **SaibaTudo-Eleicao2026**! Este é um projeto de código aberto, público e comunitário sob licença **MIT**, com o compromisso de promover a cidadania e a transparência eleitoral.

---

## 🧭 Como Contribuir

1. **Faça um Fork** do projeto no GitHub.
2. **Crie uma Branch** para sua funcionalidade ou correção:
   ```bash
   git checkout -b feature/minha-melhoria
   ```
3. **Siga os padrões de código**:
   - Para **Android (Kotlin)**: Siga o guia oficial do Android Kotlin Style Guide.
   - Para **IA/Python**: Siga o PEP 8 e documente novos formatos de prompt no Hugging Face Model Card.
4. **Escreva Testes**:
   - Testes unitários para use cases e parsers de IA.
5. **Abra um Pull Request** detalhando as alterações e motivação.

---

## 📜 Código de Conduta

O projeto mantém uma postura estritamente apartidária, plural e respeitosa. Qualquer contribuição que vise favorecer, desinformar ou violar as diretrizes do Tribunal Superior Eleitoral (TSE) será rejeitada.
